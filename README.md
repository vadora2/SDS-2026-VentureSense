# Venture Sense Group Buy Prototype

Customer ordering + admin consolidation prototype for Venture Sense grocery group buys.

## Customer Ordering Prototype Added

Open the customer ordering page here:

```txt
customer-ordering/frontend/index.html
```

Recommended local run:

```bash
cd customer-ordering/frontend
python3 -m http.server 8000
```

Then open:

```txt
http://localhost:8000
```

Included database files:

```txt
backend/database/seed-database.json
backend/database/schema.sql
backend/database/products.csv
backend/database/group_buys.csv
backend/database/buyers.csv
backend/database/orders.csv
backend/database/order_items.csv
backend/database/payments.csv
backend/database/fulfillment.csv
```
