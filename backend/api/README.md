# Backend API

Use this folder for API route files if building a coded prototype.

## Example Endpoints

```txt
GET    /group-buys/active
GET    /group-buys/:groupBuyId/products
POST   /orders
GET    /admin/orders
GET    /admin/consolidated-totals
PATCH  /admin/orders/:orderId/status
GET    /admin/packing-list
```

Refer to `docs/api-contract.md` for request and response formats.
