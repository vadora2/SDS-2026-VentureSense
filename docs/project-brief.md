# Project Brief

## Project Name

Venture Sense Grocery Group Buy Prototype

## Problem Statement

Venture Sense needs a reliable way to centralise grocery group-buy orders that currently come through scattered WhatsApp messages, manual copying, and fragmented purchase tracking.

## How Might We

How might we help Venture Sense admins centralise consumer orders so they can reduce manual consolidation of purchases and minimise errors?

## Recommended MVP Direction

The MVP should avoid making WhatsApp the main ordering system. Instead:

```txt
WhatsApp group announcement
        ↓
External mobile ordering page
        ↓
Central database
        ↓
Admin dashboard
        ↓
Manual payment / Shopify payment link
        ↓
Packing and fulfillment
```

## Core Value

Replace copy-paste consolidation with:

- Structured customer orders
- Automatic product totals
- Buyer breakdowns
- Payment status tracking
- Packing lists
- Collection/delivery status

## Primary Users

### Consumer / Buyer

Needs to:

- Browse groceries quickly
- Understand deadline and collection details
- Submit an order clearly
- Know what happens after ordering

### Venture Sense Admin

Needs to:

- View all orders in one place
- See total quantities by product
- Avoid copy-paste mistakes
- Track payment
- Generate packing lists
- Handle stock/substitution changes

### Group Host / Collection Point

Needs to:

- Know who ordered
- Know who has paid
- Know who has collected
- Contact buyers if needed

## MVP Success Criteria

The prototype is successful if:

- A buyer can submit an order without messaging admin manually.
- Admin can see the order immediately as structured data.
- Product quantities are automatically consolidated.
- Admin can see buyer-level packing details.
- Payment and fulfillment status can be updated manually.
- The demo clearly proves reduced manual consolidation work.
